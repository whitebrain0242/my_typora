## Stage7到底新增什么？

在 Stage6 的基础上增加：

### 文件信息

```text
SIZE
MDTM
```

例如：

```text
SIZE test.txt
```

返回：

```text
213 1024
```

------

```text
MDTM test.txt
```

返回：

```text
213 20260602120000
```

------

### 文件管理

```text
DELE
MKD
RMD
```

例如：

```text
DELE test.txt

MKD docs

RMD docs
```

------

### 重命名

FTP规范要求两步：

```text
RNFR old.txt
RNTO new.txt
```

会话新增：

```cpp
std::string renameFrom;
```

------

### 断点续传

新增：

```text
REST
```

会话新增：

```cpp
uint64_t restartOffset = 0;
```

流程：

```text
REST 1000
RETR movie.mp4
```

从1000字节开始发送。

------

### FEAT

用于告诉客户端：

```text
服务器支持什么功能
```

例如：

```text
FEAT
```

返回：

```text
211-Features
REST STREAM
SIZE
MDTM
UTF8
211 End
```

------

### OPTS

例如：

```text
OPTS UTF8 ON
```

返回：

```text
200 UTF8 enabled
```

------

### PASV优化

Stage4固定：

```cpp
pasvPort = 50000;
```

最终版改成：

```cpp
随机端口
50000~51000
```

避免：

```text
Address already in use
```

------

### 日志系统

替代：

```cpp
std::cout
```

例如：

```cpp
void logInfo(...)
void logError(...)
```

输出：

```text
[INFO]
[WARN]
[ERROR]
```

------

### sendfile优化（Linux）

Stage6：

```cpp
read
send
read
send
```

最终版：

```cpp
sendfile(...)
```

直接：

```text
磁盘
 ↓
内核
 ↓
socket
```

减少拷贝。

------

### 统一权限检查

避免到处写：

```cpp
if (!loggedIn)
```

抽成：

```cpp
bool requireLogin()
{
    ...
}
```

------

### RAII封装

例如：

```cpp
class Socket
{
public:

    ~Socket()
    {
        close(fd);
    }
};
```

避免：

```text
异常后忘记close
```

------

### 命令分发表

Stage2：

```cpp
if(cmd=="USER")
else if(cmd=="PASS")
else if(cmd=="PWD")
...
```

最终版：

```cpp
std::unordered_map<
    std::string,
    CommandHandler
>
```

更容易扩展。
