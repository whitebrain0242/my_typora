# 辅助函数

## sendAll()

确保全部发送完成。

-   **完整发送数据**：保证 `data` 中的所有字节都通过 socket `fd` 发送出去，除非发生错误。
-   **处理部分发送**：`send` 在阻塞模式下，可能因为内核发送缓冲区满而只发送部分数据，或因为信号中断而返回少于请求的字节数。`sendAll` 通过循环自动重试剩余部分。
-   **统一错误处理**：任何发送失败（返回 `<=0`）都会立即返回 `false`，调用者可以据此判断传输是否完全成功。

```cpp
bool sendAll(
    int fd,
    const std::string& data)
{//sent 记录已经成功发送的字节数，初始为 0。
    size_t sent = 0;

    while (sent < data.size())
    {//只要还有数据未发送，就继续循环
        ssize_t n =
            send(
                fd,
                data.data() + sent,
                data.size() - sent,
                0);

        if (n <= 0)
        {
            return false;
        }

        //累加已发送的字节数，继续循环发送剩余部分
        sent += n;
    }

    return true;
}
```

```
ssize_t n = send(fd, data.data() + sent, data.size() - sent, 0);
data.data() + sent：指向尚未发送部分的起始位置（指针偏移）。

data.size() - sent：剩余待发送的字节数。

flags = 0：无特殊选项。

send 返回值：

> 0：实际发送的字节数（可能小于请求数）。

== 0：对端已关闭连接（TCP 正常关闭）。

< 0：发生错误（如 ECONNRESET、EPIPE 等）。


```

# formatListLine()

它是 FTP 服务器中**生成目录列表条目**（类似 `ls -l` 输出）的核心函数，用于响应 `LIST` 命令。

-   **生成类似 UNIX `ls -l` 的目录列表行**，例如：`drwxr-xr-x 1 owner group 4096 subdir\r\n`
-   供 `LIST` 命令使用，通过数据连接发送给客户端。
-   客户端根据这些文本解析目录结构。

生成 LIST 输出。

```cpp
std::string formatListLine(
    const fs::directory_entry& entry)
{//确定权限字符串 perms
    std::string perms;
//目录以 d 开头，普通文件以 - 开头。

//后面 9 个字符硬编码为 rwxr-xr-x（目录）或 rw-r--r--（文件）。
    if (entry.is_directory())
        perms = "drwxr-xr-x";
    else
        perms = "-rw-r--r--";
//. 获取文件大小
    uintmax_t size = 0;
//只有普通文件才需要显示大小（目录通常显示 0 或 4096，这里保持为 0）
    if (entry.is_regular_file())
    {
        size = entry.file_size();
    }

    std::ostringstream oss;
//末尾加上 \r\n 作为行结束符（FTP 协议要求）。
    oss//硬编码了链接数（1）、所有者名称（owner）、组名称（group）
        << perms
        << " 1 owner group "
        << size
        << " "
        << entry.path().filename().string()
        << "\r\n";

    return oss.str();
}
```

# handleLIST()

新增：



-   处理 FTP `LIST` 命令（无参数），将当前工作目录（`currentDir`）的内容以**类 `ls -l` 格式**通过数据连接发送给客户端。
-   客户端通常收到后显示为目录和文件列表。
-   依赖于被动模式（`PASV`）：必须先发送 `PASV` 获得监听端口，然后 `LIST` 利用该数据连接发送列表。

```cpp
void handleLIST()
{//登录验证
    if (!loggedIn)
    {
        sendReply(
            530,
            "Please login");
        return;
    }
//检查是否已设置被动监听
    //LIST 需要一个数据连接。如果客户端此前没有发送 PASV 命令（即 pasvListenFd 无效），则无法建立数据连接，回复 425（无法打开数据连接）。
    if (pasvListenFd < 0)
    {
        sendReply(
            425,
            "Use PASV first");

        return;
    }
//150 表示“文件状态正确，即将打开数据连接”。客户端收到后准备接收数据。
    sendReply(
        150,
        "Opening ASCII mode data connection");
//接受数据连接
    int dataFd =
        acceptDataConnection();

    if (dataFd < 0)
    {
        sendReply(
            425,
            "Data connection failed");

        return;
    }
//遍历目录并发送列表
    try
    {
        for (const auto& entry :
             fs::directory_iterator(
                 currentDir))
        {//对每个条目调用 formatListLine 生成一行类似于 ls -l 的文本（末尾已加 \r\n）。
            auto line =
                formatListLine(entry);
//通过 sendAll 将每行数据发送到数据 socket，保证全部发送
            sendAll(
                dataFd,
                line);
        }

        close(dataFd);
//回复 226（传输成功）。
        sendReply(
            226,
            "Transfer complete");
    }//回复 550（请求的操作未执行，文件不可用
    catch (...)
    {
        close(dataFd);

        sendReply(
            550,
            "Directory read failed");
    }
}
```

# handleNLST()

新增：

`NLST`（Name List）用于**获取目录下的文件名列表**（不包含文件大小、权限、时间等属性）。输出通常是每行一个文件名，没有额外格式。

-   与 `LIST` 的区别：

    `LIST` 返回详细列表（类似 `ls -l`），包含权限、大小、时间等。

    `NLST` 只返回文件名（类似 `ls -1`），简洁且易于解析

```cpp
void handleNLST()
{
    if (!loggedIn)
    {
        sendReply(
            530,
            "Please login");

        return;
    }
//NLST 也需要数据连接，因此必须先执行 PASV（或 PORT，但你的实现只支持 PASV）。如果没有监听 socket，回复 425。
    if (pasvListenFd < 0)
    {
        sendReply(
            425,
            "Use PASV first");

        return;
    }
//150 表示即将打开数据连接，准备传输。
    sendReply(
        150,
        "Opening data connection");

    int dataFd =
        acceptDataConnection();

    if (dataFd < 0)
    {
        sendReply(
            425,
            "Data connection failed");

        return;
    }

    try
    {//遍历当前真实路径下的所有条目。
        for (const auto& entry :
             fs::directory_iterator(
                 currentDir))
        {//获取纯文件名（不含路径）
            std::string line =
                entry.path()
                    .filename()
                    .string();

            line += "\r\n";

            sendAll(
                dataFd,
                line);
        }

        close(dataFd);
//回复 226（传输成功）
        sendReply(
            226,
            "Transfer complete");
    }
    catch (...)
    {
        close(dataFd);

        sendReply(
            550,
            "Directory read failed");
    }
}
```
