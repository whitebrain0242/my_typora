# handleTYPE()

`TYPE` 命令用于指定**数据传输时的表示类型**，影响文件内容在传输过程中的编码转换

| 参数 | 含义                | 说明                                                         |
| :--- | :------------------ | :----------------------------------------------------------- |
| `I`  | **Image**（二进制） | 以原始字节流传输，不做任何转换。适用于所有文件（包括可执行文件、压缩包、图片等）。 |
| `A`  | **ASCII**（文本）   | 传输文本文件时，进行换行符转换（例如服务器上的 `\n` 转换为客户端的 `\r\n` 或相反）。适用于纯文本文件。 |

其他类型（如 `E`、`L`）极少使用。

```cpp
void handleTYPE(
    const std::string& arg)
{
    if (arg == "I")
    {
        binaryMode = true;
//回复 200（命令成功）
        sendReply(
            200,
            "Binary mode");
    }
    else if (arg == "A")
    {
        binaryMode = false;

        sendReply(
            200,
            "ASCII mode");
    }
    else
    {//如果参数不是 I 或 A，回复 504
        sendReply(
            504,
            "Unknown TYPE");
    }
}
```

# sendFile()

新增辅助函数

-   **从服务器文件系统读取指定文件**（`file` 是真实绝对路径，已通过 `resolvePath` 安全检查）。
-   **通过数据连接 socket（`dataFd`）将文件内容完整发送给客户端**。
-   **返回值**：`true` 表示全部发送成功，`false` 表示过程中发生错误（打开文件失败、读取失败、发送失败等）。

```cpp
bool sendFile(
    int dataFd,
    const fs::path& file)
{
    constexpr size_t BUF_SIZE =
        64 * 1024;

    char buffer[BUF_SIZE];
//std::ios::binary 以二进制模式打开，不做换行符转换（确保原样传输）。

//如果打开失败（文件不存在、权限不足等），直接返回 false，上层（handleRETR）可回复 550
    std::ifstream in(
        file,
        std::ios::binary);

    if (!in)
    {
        return false;
    }

    while (in)
    {
        in.read(
            buffer,
            sizeof(buffer));

        std::streamsize n =
            in.gcount();//// 实际读取的字节数

        if (n <= 0)
        {
            break;
        }

        size_t sent = 0;
//send 可能只发送部分数据（网络拥塞、缓冲区满），因此需要循环直到该块完全发送。

//如果 send 返回 <=0（连接关闭或错误），立即返回 false，上层应中断传输。


        while (sent <
               static_cast<size_t>(n))
        {
            ssize_t s =
                send(
                    dataFd,
                    buffer + sent,
                    n - sent,
                    0);

            if (s <= 0)
            {
                return false;
            }

            sent += s;
        }
    }

    return true;
}
```

# recvFile()

-   **从数据连接（`dataFd`）读取客户端发送的文件内容**。
-   **将读取到的数据写入服务器指定的文件（`file`）**。
-   **返回值**：`true` 表示成功接收并写入全部数据；`false` 表示失败（无法打开文件、接收错误等）。

```cpp
bool recvFile(
    int dataFd,
    const fs::path& file)
{
    constexpr size_t BUF_SIZE =
        64 * 1024;
//使用 64KB 的缓冲区，一次接收一块数据，避免逐字节接收带来的高系统调用开销。
    char buffer[BUF_SIZE];

    //打开数据文件
    //std::ios::binary 以二进制模式打开，不对换行符做任何转换，确保原样写入客户端传来的数据。

//如果打开文件失败（目录不存在、权限不足、路径非法等），返回 false，上层（handleSTOR）应回复 550。
    std::ofstream out(
        file,
        std::ios::binary);

    if (!out)
    {
        return false;
    }

    while (true)
    {
        ssize_t n =
            recv(
                dataFd,
                buffer,
                sizeof(buffer),
                0);

        if (n == 0)//  // 对端正常关闭数据连接 → 传输完成
        {
            break;
        }

        if (n < 0)// 接收错误（如网络中断）

        {
            return false;
        }

        out.write(// 将数据写入文件
            buffer,
            n);
    }

    return true;
}
```

------

| 特性     | `sendFile`（下载）                | `recvFile`（上传）                |
| :------- | :-------------------------------- | :-------------------------------- |
| 数据方向 | 服务器 → 客户端                   | 客户端 → 服务器                   |
| 源       | 服务器文件系统（`std::ifstream`） | 数据 socket（`recv`）             |
| 目的     | 数据 socket（`send`）             | 服务器文件系统（`std::ofstream`） |
| 循环条件 | 读取文件直到 EOF                  | 接收 socket 直到关闭              |
| 结束标志 | `in.gcount() <= 0`                | `recv` 返回 `0`                   |

# handleRETR()

下载正确的 FTP 协议流程：登录检查 → 路径解析 → 文件存在性/类型检查 → 确保被动模式已启用 → 建立数据连接 → 发送文件 → 回复结果。代码结构易于理解，错误处理也比较完善。

| 步骤                          | 作用                                               |
| :---------------------------- | :------------------------------------------------- |
| `resolvePath(arg)`            | 将客户端路径转为服务器绝对路径，同时做路径穿越检查 |
| `fs::exists(file)`            | 确认文件存在                                       |
| `fs::is_regular_file(file)`   | 确保不是目录或特殊文件                             |
| `pasvListenFd < 0` 检查       | 强制要求客户端先发 `PASV`                          |
| `sendReply(150)`              | 通知客户端准备数据连接                             |
| `acceptDataConnection()`      | 获取数据 socket（等待客户端连接）                  |
| `sendFile(dataFd, file)`      | 实际传输文件内容                                   |
| 根据 `ok` 回复 `226` 或 `426` | 告知传输结果                                       |
| `catch (...)`                 | 捕获路径解析异常，回复 `550`                       |

```cpp
void handleRETR(
    const std::string& arg)
{
    if (!loggedIn)
    {
        sendReply(
            530,
            "Please login");
        return;
    }

    try
    {
        auto file =
            resolvePath(arg);

        if (!fs::exists(file))
        {
            sendReply(
                550,
                "File not found");

            return;
        }

        if (!fs::is_regular_file(file))
        {
            sendReply(
                550,
                "Not a file");

            return;
        }

        if (pasvListenFd < 0)
        {
            sendReply(
                425,
                "Use PASV first");

            return;
        }

        sendReply(
            150,
            "Opening data connection");

        int dataFd =
            acceptDataConnection();

        if (dataFd < 0)
        {
            sendReply(
                425,
                "Data connection failed");

            return;
        }

        bool ok =
            sendFile(
                dataFd,
                file);

        close(dataFd);

        if (ok)
        {
            sendReply(
                226,
                "Transfer complete");
        }
        else
        {
            sendReply(
                426,
                "Transfer aborted");
        }
    }
    catch (...)
    {
        sendReply(
            550,
            "Invalid path");
    }
}
```

# handleSTOR()

上传

-   **处理 `STOR` 命令**：客户端发送 `STOR <filename>` 请求上传一个文件。
-   **接收数据**：等待客户端通过已建立的数据连接发送文件内容。
-   **保存到服务器**：将接收到的数据写入由 `resolvePath` 确定的安全路径（位于 FTP 根目录下）。
-   **响应**：成功回复 `226`，失败回复 `426` 或 `550`。

```cpp
void handleSTOR(
    const std::string& arg)
{
    if (!loggedIn)
    {
        sendReply(
            530,
            "Please login");

        return;
    }

    try
    {//esolvePath(arg) 将客户端提供的虚拟路径（绝对或相对）转换为服务器真实绝对路径，并执行路径穿越检查（pathInsideRoot）。
        auto file =
            resolvePath(arg);
// 检查被动模式是否已激活
        if (pasvListenFd < 0)
        {
            sendReply(
                425,
                "Use PASV first");

            return;
        }
//150 表示“即将打开数据连接”，客户端收到后应准备发送数据。

//acceptDataConnection() 会阻塞等待客户端连接到之前 PASV 创建的监听端口，返回数据 socket。若超时或失败，回复 425
        sendReply(
            150,
            "Opening data connection");

        int dataFd =
            acceptDataConnection();

        if (dataFd < 0)
        {
            sendReply(
                425,
                "Data connection failed");

            return;
        }
//recvFile 负责从 dataFd 循环读取数据，并写入到 file 路径（以二进制模式覆盖写入）。

//传输结束后关闭数据 socket（无论成功与否）。


        bool ok =
            recvFile(
                dataFd,
                file);

        close(dataFd);
//成功：226（传输完成）。

/失败：426（数据连接关闭，传输中断）。
        if (ok)
        {
            sendReply(
                226,
                "Transfer complete");
        }
        else
        {
            sendReply(
                426,
                "Transfer aborted");
        }
    }
    catch (...)
    {
        sendReply(
            550,
            "Upload failed");
    }
}
```
