# pathInsideRoot()

判断路径是否还在 FTP 根目录内部

```cpp
//检查一个给定的绝对路径是否位于 FTP 根目录之内，防止客户端通过 ../ 等手法进行路径遍历攻击（Directory Traversal）。

bool pathInsideRoot(
    const fs::path& path)
{
    auto normalized =
        fs::weakly_canonical(path);
//规范化根目录，确保 rootDir 是绝对路径且没有 .、..
    auto root =
        fs::weakly_canonical(rootDir);
//转换为字符串并比较前缀
   // rootStr 和 pathStr 是操作系统原生路径字符串（如 /home/ftp_root）。

//pathStr.compare(0, rootStr.size(), rootStr)：
//从 pathStr 的索引 0 开始，比较 rootStr.size() 个字符是否等于rootStr。

//如果返回 0，表示 pathStr 以 rootStr 开头（即路径在根目录内）。
    auto rootStr =
        root.string();

    auto pathStr =
        normalized.string();

    return
        pathStr.compare(
            0,
            rootStr.size(),
            rootStr) == 0;
}
```

# resolvePath()

把 FTP 路径转真实路径

-   **输入**：客户端发送的路径字符串 `ftpPath`，例如：
    -   绝对路径：`/pub/file.txt`
    -   相对路径：`docs/readme.txt` 或 `../etc/passwd`

-   **输出**：服务器文件系统上的**绝对路径**（例如 `/home/ftp_root/pub/file.txt`），前提是该路径在根目录 `rootDir` 内。
-   **安全**：如果检测到路径试图逃逸根目录（如包含 `..` 且最终路径不在 `rootDir` 下），则抛出异常。

1.  **识别路径类型**（绝对路径 vs 相对路径）。
2.  **拼接基准目录**（根目录或当前工作目录）。
3.  **标准化路径**（去掉 `.`、`..`、多余的 `/`）。
4.  **安全校验**（是否逃逸根目录）。
5.  **返回安全的绝对路径**（或抛出异常）。

```cpp
fs::path resolvePath(
    const std::string& ftpPath)
{
    fs::path result;

    //--------------------------------------------------
    // 绝对路径
    //--------------------------------------------------

    //以 / 开头的路径表示相对于 FTP 根目录
    //rootDir 是服务器的 FTP 根目录（绝对路径，如 /home/ftp_root）。

//ftpPath.substr(1) 去掉开头的 /，得到相对子路径。例如 /pub/file → pub/file。

//rootDir / "pub/file" 得到 /home/ftp_root/pub/file。
    
    
    
    if (!ftpPath.empty() &&
        ftpPath[0] == '/')
    {
        result =
            rootDir /
            ftpPath.substr(1);
    }

    //--------------------------------------------------
    // 相对路径
    //--------------------------------------------------

    //不以 / 开头（或空字符串），表示相对于当前工作目录 currentDir。
    else
    {//currentDir 是当前工作目录（绝对路径，且一定在 rootDir 之下）。

//直接将 currentDir 与 ftpPath 拼接。如果 ftpPath 是 .. 或包含 ..，拼接后会产生诸如 /home/ftp_root/sub/../etc 这样的中间路径。
        result =
            currentDir /
            ftpPath;
    }

    //lexically_normal() 是 std::filesystem::path 的成员函数，纯语法上移除路径中的 . 和 ..，以及多余的 /
    //它只做字符串处理，不访问文件系统（
    
    result =
        result.lexically_normal();

    if (!pathInsideRoot(result))
    {
        throw std::runtime_error(
            "path escape detected");
    }

    return result;
}
```

# toVirtualPath()

真实路径转 FTP 路径

例如：

```text
/home/me/ftp_root/docs
```

变：

```c++
/docs

std::string toVirtualPath(
    const fs::path& realPath)
{
//计算 realPath 相对于 rootDir 的相对路径。
    
    auto rel =
        fs::relative(
            realPath,
            rootDir);

    //当 realPath 就是 FTP 根目录本身时，相对路径为空。
    if (rel.empty())
    {
        return "/";
    }

    //rel.generic_string()：将路径转换为使用正斜杠 / 的字符串（跨平台统一格式）。例如在 Windows 上 rel 可能是 pub\file.txt，
    return "/" +
           rel.generic_string();
}
```

-   `realPath` = `/home/ftp_root/pub/file.txt`
-   `rootDir` = `/home/ftp_root`
-   结果 `rel` = `pub/file.txt`（类型为 `fs::path`）

客户端要看的是虚拟路径

# handleCWD()

新增

切换工作目录CWD+路径，会改变绘画中的currentDir真是绝对路径

```cpp
void handleCWD(
    const std::string& arg)
{//登陆检查，必要才能CWD
    
    if (!loggedIn)
    {
        sendReply(
            530,
            "Please login");
        return;
    }

    c
    try
    {//虚拟路径转换为真实路径
        auto target =
            resolvePath(arg);

        //先看这个真实路径存不存在
        if (!fs::exists(target))
        {
            sendReply(
                550,
                "Directory not found");
            return;
        }

        //检查是否为目录，不鞥切换到一个文件
        if (!fs::is_directory(target))
        {
            sendReply(
                550,
                "Not a directory");
            return;
        }

        //更新当前目录，发送成功响应
        currentDir = target;

        sendReply(
            250,
            "Directory changed");
    }
    catch (...)
    {
        sendReply(
            550,
            "Invalid path");
    }
}
```

| 检查项                    | 必要性                    | 不检查的后果                                         |
| :------------------------ | :------------------------ | :--------------------------------------------------- |
| 登录状态                  | 防止未授权用户改变目录    | 允许匿名访问目录结构，可能泄露信息                   |
| 路径解析（`resolvePath`） | 防止 `../` 越界和路径注入 | 用户可以读取根目录外的文件（严重安全漏洞）           |
| 目标存在性                | 确保切换到的目录真实存在  | 设置一个不存在的目录，后续命令可能失败或产生奇怪行为 |
| 目标是目录                | 确保 `CWD` 语义正确       | 可以“进入”一个普通文件，导致后续操作异常             |
| 异常捕获                  | 健壮性                    | 任何解析/文件系统异常都会导致服务器崩溃              |

# handleCDUP()

新增

处理 FTP `CDUP`（Change Directory to Up）命令的函数，`CDUP` 是 `CWD ..` 的简写形式，用于将当前工作目录切换到**父目录**（上一级）。

```cpp
void handleCDUP()
{
    handleCWD("..");
}
```
