# 整个项目最重要的安全问题

客户端：

```text

```

如果不检查：

```text

/etc/shadow
```

都可能被访问。

这是 FTP 服务器最经典漏洞。

所以必须实现：


# pathInsideRoot()

判断路径是否还在 FTP 根目录内部

```cpp
bool pathInsideRoot(
    const fs::path& path)
{
    auto normalized =
        fs::weakly_canonical(path);

    auto root =
        fs::weakly_canonical(rootDir);

    auto rootStr =
        root.string();

    auto pathStr =
        normalized.string();

    return
        pathStr.compare(
            0,
            rootStr.size(),
            rootStr) == 0;
}
```

# resolvePath()

把 FTP 路径转真实路径

```cpp
fs::path resolvePath(
    const std::string& ftpPath)
{
    fs::path result;

    //--------------------------------------------------
    // 绝对路径
    //--------------------------------------------------

    if (!ftpPath.empty() &&
        ftpPath[0] == '/')
    {
        result =
            rootDir /
            ftpPath.substr(1);
    }

    //--------------------------------------------------
    // 相对路径
    //--------------------------------------------------

    else
    {
        result =
            currentDir /
            ftpPath;
    }

    result =
        result.lexically_normal();

    if (!pathInsideRoot(result))
    {
        throw std::runtime_error(
            "path escape detected");
    }

    return result;
}
```

```text
std::string toVirtualPath(
    const fs::path& realPath)
{
    auto rel =
        fs::relative(
            realPath,
            rootDir);

    if (rel.empty())
    {
        return "/";
    }

    return "/" +
           rel.generic_string();
}
```

# handleCWD()

新增

```cpp
void handleCWD(
    const std::string& arg)
{
    if (!loggedIn)
    {
        sendReply(
            530,
            "Please login");
        return;
    }

    try
    {
        auto target =
            resolvePath(arg);

        if (!fs::exists(target))
        {
            sendReply(
                550,
                "Directory not found");
            return;
        }

        if (!fs::is_directory(target))
        {
            sendReply(
                550,
                "Not a directory");
            return;
        }

        currentDir = target;

        sendReply(
            250,
            "Directory changed");
    }
    catch (...)
    {
        sendReply(
            550,
            "Invalid path");
    }
}
```
