# 顺序表和链表的区别

顺序表其实就是数组加入一些规则，比如删除 扩容 长度管理等线性表操作

|   对比维度    |                  顺序表                  |                  链表                  |
| :-----------: | :--------------------------------------: | :------------------------------------: |
|   存储方式    |              连续的内存空间              |      分散的内存空间 需要用到指针       |
|   访问元素    |      随即访问，直接使用索引，效率高      |       顺序访问，从头遍历，效率低       |
| 插入/删除元素 |              先移动，后插入              |            修改指针指向即可            |
|  空间利用率   |                满了要扩容                |      按需分配五浪费，新增节点即可      |
|   适用场景    | 访问频繁，元素数量固定，要求速度高时间短 | 插入删除频繁，数量变化大，无法预估内存 |

相同空间，顺序表的存储密度大

**随机存取**：访问时间固定，直接访问任何位置的元素

**顺序存取**：访问时间线性，只能顺序访问元素，不能直接跳转

存取就是修改
