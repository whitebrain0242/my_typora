# Go 后端实习 9 周备战计划 · 每日任务清单

> 总周期：10/14 ~ 12/15（共 9 周）

每周目标投入：36h（第 9 周考试周可降至 20~24h）

***

## 第 1 周｜10/14--10/20：Go 语言、TCP 和测试底座

> 时间拆分：Go 15h / 算法 6h / 八股 6h / 6.5840 4h / 开源 3h / 投递 2h

### 📅 10/14（周二）约 5h

- [ ] **G1（2h）**：安装 Go，建立 Git 仓库；掌握 module、package、struct、方法、指针、interface、error。写命令行通讯录（增删查），要求模块分层、错误显式返回。验收：`go test ./...` 通过；能解释值接收者/指针接收者。

- [ ] **算法（2h）**：数组、哈希、双指针方向，做 2~3 道题，每题写时间/空间复杂度 + 一个边界用例。

- [ ] **八股（1h）**：TCP 三次握手 / 四次挥手。

### 📅 10/15（周三）约 5h

- [ ] **G2（2h）**：goroutine、channel、WaitGroup、Mutex；写 10 worker 执行 100 task 的任务池。验收：无任务遗漏/重复；关闭后无悬挂 worker；`go test -race ./...` 无竞态。

- [ ] **算法（2h）**：数组、哈希、双指针方向，做 2~3 道题。

- [ ] **八股（1h）**：TIME_WAIT、进程与线程。

### 📅 10/16（周四）约 5h

- [ ] **G3（2h）**：net.Listen/Accept/Dial，独立写 TCP Echo Server 和 Client。验收：≥10 个客户端并发连接，单连接多条消息正确回显；Ctrl+C 可退出。

- [ ] **6.5840 M1（2h）**：配置 6.5840 实验环境，阅读 MapReduce 任务要求与测试。

- [ ] **八股（1h）**：阻塞与非阻塞 IO。

### 📅 10/17（周五）约 5h

- [ ] **G4（2h）**：理解 TCP 字节流，写 4 字节大端长度前缀帧。验收：同一连接连续两条消息、拆分写入、空消息、非法长度均有测试；限制最大消息长度。

- [ ] **6.5840 M2（2h）**：画 Coordinator/Worker 交互图，不照搬实验答案。

- [ ] **开源 O1（1h）**：浏览 OSPP 官方项目页，建立候选表初版（语言、入门难度、构建方式、Issue、导师/维护者反馈）。

### 📅 10/18（周六）约 6h

- [ ] **G5（2h）**：连接读写超时、关闭、错误处理；写 README 的启动命令。验收：客户端断开后 goroutine 正常退出，无 panic。

- [ ] **G6（2h）**：学习 testing、table-driven tests、`-race`、gofmt；对 Echo 服务补 5 个以上测试用例。

- [ ] **投递（2h）**：建立岗位台账，记录公司、岗位、链接、学历年级要求、实习周期、投递状态。

### 📅 10/19（周日）约 6h

- [ ] **G7（3h）**：补 Go slice/map、defer、context、JSON，整理代码并独立重写一段关键读帧逻辑。

- [ ] **开源 O1（2h）**：浏览 CloudWeGo、OpenTelemetry Go，完善候选表。

- [ ] **算法（1h）**：复刷本周错题或补 1 道新题。

### 📅 10/20（周一）约 5h

- [ ] **算法（1h）**：本周算法收尾，总计完成 7~9 道不同题。

- [ ] **八股（3h）**：epoll LT/ET、Go goroutine 基础；本周八股知识点口述复盘。

- [ ] **✅ 周验收（1h）**：能不看 AI 生成代码独立重写 Echo Server 的关键流程；至少 5 个测试；Git 仓库可克隆运行。

## 第 2 周｜10/21--10/27：Go 并发工程化 + RPC 设计

> 时间拆分：Go/RPC 15h / 算法 6h / 八股 6h / 6.5840 4h / 开源 3h / 投递 2h

### 📅 10/21（周二）约 5h

- [ ] **G1（2h）**：学 context.WithTimeout/WithCancel、select、channel 关闭原则；给 Echo 增加请求/连接超时。

- [ ] **算法（2h）**：链表方向，做 2~3 道题。

- [ ] **八股（1h）**：Go slice 扩容机制。

### 📅 10/22（周三）约 5h

- [ ] **G2（2h）**：学习 TCP 半包、粘包、读写循环；写 fuzz 或随机切分帧测试。

- [ ] **算法（2h）**：二分方向，做 2~3 道题。

- [ ] **八股（1h）**：Go map 并发安全。

### 📅 10/23（周四）约 5h

- [ ] **G3（2h）**：写最小 RPC 设计文档：RequestID, Service, Method, Payload；ResponseID, Error, Payload；明确最大帧、超时和错误码。

- [ ] **6.5840 M（2h）**：启动 MapReduce Lab；明确 map/reduce 中间文件、任务状态、重试条件；先做最小可运行流程。

- [ ] **八股（1h）**：Go channel 原理。

### 📅 10/24（周五）约 5h

- [ ] **G4（2h）**：确定最小 API：Server.Register(name, handler)、Client.Call(ctx, service, method, req)；画时序图。

- [ ] **开源 O（1h）**：选定一个主攻仓库，克隆下来。

- [ ] **八股（2h）**：Go mutex、context 原理。

### 📅 10/25（周六）约 6h

- [ ] **G5（2h）**：实现 codec（先 JSON，后续按需 Protobuf）；协议编码/解码与业务逻辑分离。

- [ ] **G6（2h）**：设计测试矩阵：正常请求、错误方法、坏帧、超时、并发、断线；建 CI（可先本地脚本）。

- [ ] **投递（2h）**：写简历骨架，只写已完成项目；联系学长了解实习到岗周期。

### 📅 10/26（周日）约 6h

- [ ] **G7（3h）**：独立从空文件写一遍 RPC 帧编码/解码与单元测试，整理接口注释。

- [ ] **6.5840 M（2h）**：继续 MapReduce 最小流程调试。

- [ ] **开源 O（1h）**：读目标仓库 CONTRIBUTING，跑目标包测试，记录实际报错。

### 📅 10/27（周一）约 5h

- [ ] **算法（2h）**：栈队列方向 1~2 道 + 复刷上周 2 道错题；本周总计 7~9 道新题。

- [ ] **八股（2h）**：TCP 字节流与 HTTP/1.1 长连接。

- [ ] **✅ 周验收（1h）**：协议测试通过；能够画出 RPC 调用时序图并解释超时、并发和错误处理；开源仓库至少尝试构建。

## 第 4 周｜11/04--11/10：并发 RPC + 超时 + 断线

> 时间拆分：RPC 15h / 算法 6h / 八股 6h / 6.5840 4h / 开源 3h / 投递 2h

### 📅 11/04（周二）约 5h

- [ ] **八股（1h）**：锁与死锁。

- [ ] **R2（2h）**：单 TCP 连接并发 Call，使用单独读循环分发 Response。

- [ ] **算法（2h）**：堆方向，做 2~3 道题。

- [ ] **八股（1h）**：goroutine 泄漏。

### 📅 11/06（周四）约 5h

- [ ] **6.5840 M（2h）**：MapReduce 收尾；若未通过，记录未过的用例与原因，不无限延迟 RPC。

### 📅 11/07（周五）约 5h

- [ ] **投递（2h）**：简历 v1；开始每周 5~10 个高度匹配岗位的试投，并记录反馈。
