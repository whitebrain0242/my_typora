## 我的易错点

-   怎么创建一个map？而且对于map的返回值是什么？
     大概就是~    **x:=map【键类型】（值类型）{}**    ~
     对于map的返回值来说
     第一种：~ val:=mymap[key] ~ 但是无法分辨key到底是否存在，不存在的话就是0
     第二种：~ val,ok :=mymap[key] ~第一个是键对应的值，第二个是key是否在map中存在
-  怎么实现while(true)功能？
      直接使用for{}没有任何参数之类的
-  怎么遍历数组？数组的返回值又是什么？
     ~ for i,value :=range nums {} ~
      第一个返回值是数组下标，第二个返回值是 nums[i] 也就是 i 索引下的值，是一个**副本**，改变副本并不会改变原值，如果想改变原值就要通过nums[i]=？进行修改
      然后这种情况下，如果任何一个不想要这个值，那么就是用 __ 代替，丢掉对应内容
      ~ for i :=range nums{} ~
      只有一个返回值的情况下，i代表就是索引下标
  -  if的使用？
     if 【第一部分：定义变量】 ; 【第二部分：布尔判断条件】
     if i, ok := idx [target-x]; ok很方便一行就写完了
-  怎么返回指定数组？
     空数组》return nil
     非空数组》return []int{值}

```go
func twoSum(nums []int, target int) []int {
	idx:=map[int]int{}
    for j,x :=range nums{
		if val,ok :=idx[target-x];ok{
			return []int{val,j}
		}
		idx[x]=j
	}
	return nil
}
```

## 参考思路

（独立完成后再整理）
 a. 首先是创建一个map,因为返回值是索引，所以键是数字，值是索引
     
    
b. 其次是遍历数组，然后看这个数的另外一个数字是否存在于此数字左边，存在就返回索引
     
c. 不存在返回空数组
