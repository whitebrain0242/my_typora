```go 
//使用堆排序将nums升序排列
func sortArray(nums []int) []int {
    n:=len(nums)
    if n<=1{
        return nums
    }
    //先从下向上下沉
    for i:=(n-2)/2;i>=0;i--{
        siftDown(nums,i,n-1)
    }
    //再从上向下下沉
    for end:=n-1;end>0;end--{
        nums[0],nums[end]=nums[end],nums[0]
        siftDown(nums,0,end-1)
    }
    return nums
}
//下沉函数:nums是整个树,k是调整元素的下标,end是可以调整的最后一个元素的下标
func siftDown(nums []int,k int ,end int){
    for {
        child:=k*2+1//左孩子
        //如果这个孩子不存在(超出范围)
        if child>end{
            break
        }
        if child+1<=end&&nums[child]<nums[child+1]{
            child++
        }
        //判断当前节点的值是否比左右孩子更大
        if nums[child]<nums[k]{
            break
        }
        nums[child],nums[k]=nums[k],nums[child]
        k=child
    }
}
```
2. 快速排序
```go
func partition (nums []int)int{
//左右指针向中间走,排好左右的值
    n:=len(nums)
    i:=rand.Intn(n)
    num:=nums[i]
    l,r:=1,n-1
    nums[i],nums[0]=nums[0],nums[i]
    for{
        for l<=r&&nums[l]<num{
            l++
        }
        for l<=r&&nums[r]>num{
            r--
        }
        if l>=r{
            break
        }
        nums[l],nums[r]=nums[r],nums[l]
        l++
        r--
    }
    nums[r],nums[0]=nums[0],nums[r]
    return r
}
func sortArray(nums []int) []int {
//递归处理左右的值
    if len(nums) <= 1 {
        return nums
    }
    i:=partition(nums)
    sortArray(nums[:i])
    sortArray(nums[i+1:])
    return nums
}
```
## 参考思路

（独立完成后再整理）
1. 首先要知道,数组是按照根左右进行排序的,所以说下标`i`的左孩子是`i*2+1`,右孩子是`i*2+2`,并且最后一个非叶子节点是`(n-2)/2`,(n是数组长度)
2. 其实最重要的是一个下沉函数,那么这个下沉函数怎么实现呢?
     为了让数组变成一个大根堆,(也就是根节点比两个孩子节点都要大的完全二叉树,),我们需要比较根节点和左右孩子的大小,**注意不要超出范围,因为最大值和最后一个元素交换了位置**,
     如果根节点大,那么就不用管
     如果孩子更大(这里还要比较两个孩子的大小),那么和较大的孩子进行交换
    完了之后我们只是下沉了一次,但是不确定这个值和下面的值的关系,所以我们继续下沉这个值
3. 我们创建一个堆,只需要从下面的元素向上遍历,对每一个元素下沉一次,然后再来一各循环:交换顶和最后一个元素,然后我们把这个刚交换上来的数字进行下沉
4. 最后返回就好了

## 时间复杂度
1. 从下向上建立一个堆:On
     - 最底层叶子：数量约 `n/2`，下沉 0 层
    - 倒数第二层：约 `n/4` 个节点，最多下沉 1 层
    - 倒数第三层：约 `n/8` 个节点，最多下沉 2 层
    - …
    总代价 ≈ `n/4 × 1 + n/8 × 2 + n/16 × 3 + ...`，这个级数收敛到 **O(n)**，不是 O(n log n)。
2. 从上到下排序O(n log n)
     - 循环 `n-1` 轮
    - 每轮调用一次 `siftDown`，最坏下沉 `log n` 层 → O(log n)
    - 总计 `(n-1) × O(log n)` = **O(n log n)**
3. 最后总共是**O(n log n)**

快速排序平均
**`O(n log n)`** **最好：`O(n log n)`** **最坏：`O(n^2)`**
## 空间复杂度
O1只是用了几个临时变量
**额外数组空间：`O(1)`** **递归栈空间：平均 `O(log n)`，最坏 `O(n)`**
