```go
func maxArea(height []int) (ans int) {
    left,right:=0,len(height)-1
    for left<right{
        space:=(right-left)*min(height[left],height[right])
        ans=max(ans,space)
        if height[left]<height[right]{
            left++
        }else{
            right--
        }
    }
    return 
}
```


## 参考思路

（独立完成后再整理）
1. 首先我们使用的是双指针做法，既要来考虑索引距离也要考虑高度，那么我们维护两个值，一个是前指针，一个是尾指针，然后这样的话，最开始的时候就是索引距离最大的时候
2. 那么我们的循环条件其实就是`left<right`
3. 我们怎么更新指针呢？我们既然是从索引距离最大开始的，后面索引距离一定减小，为的是能获得更高的高度，所以说哪边矮我们就把指针向中间移动就好了
