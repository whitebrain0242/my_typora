```go
func longestConsecutive(nums []int) int {
	Map:=map[int]bool{}
	ans:=0
	for _,num :=range nums{
		Map[num]=true
	}
	for x:=range Map{
		if Map[x-1]{
			continue
		}
		y:=x+1
		for Map[y]{
			y++
		}
		ans =max(ans,y-x)
	}
	return ans 
}
```


## 参考思路

（独立完成后再整理）
首先，关于正确的不使用排序的方法：
a. 首先我们记录最大连续长度需要寻找一个值存在与否？我们使用哈希set进行记录
b. 其次我们把所有值保存在set中之后呢？我们怎么记录最大连续长度？**我们维护一个x和y**
    遍历这个set得到**x**:**查找这个值的上一个是否存在**，判断是不是序列头！！！存在的话代表这个是连续的，我们遍历下一个
     如果不存在的话，首先我们维护一个**y=x+1**,然后去看y值是否在set中存在
     如果存在的话，说明这个也是连续的，我们把y后移
     如果不存在的话，说明这个连续序列从这里停止了，说明此时的y在SET中不存在，那么我们可以把这一次的连续长度计算出来**y-x**，然后与之前记录的最大长度进行比较大小，更新答案
c. 最后返回答案

## 时间复杂度
参考思路中的复杂度是\(O(n)\)
创建哈希表的for循环是On,遍历哈希表 是Ou,内层的`for has[y]`，成功检查次数加失败检查次数一定是等于不同数字的个数，而不同数字的个数u是<=n的，所有这部分是Ou
最后加起来  T(n)=O(n)+O(u)+O(u)+O(u)=On


## 空间复杂度
注意这里的n是不同数字的个数
空间复杂度是On，主要的原因是因为创建的哈希表的最坏情况是存储n各不同的数字
所以说哈希表的创建是On，其他变量是O1，相加起来就是On
