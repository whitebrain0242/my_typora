```go
func rotate(nums []int, k int)  {
    k%=len(nums)
    slices.Reverse(nums)
    slices.Reverse(nums[:k])
    slices.Reverse(nums[k:])
}
```

## 参考思路

（独立完成后再整理）
1. 首先其实我们就是要把后k个元素放到数组前面,那么我们假设原数组是`A+B`,我们想要的答案是`B+A`
2. 那么我们把整个数组进行反转之后,得到的是`B逆+A逆`,我们再分别把A逆和B逆反转一下就好了 
3. 这道题还有一个重点是如果k大于len(nums),那么我们要对于整个长度进行取余
