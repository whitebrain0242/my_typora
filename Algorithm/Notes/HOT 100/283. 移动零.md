     第一次做的时候，首先是想到先使用for循环遍历整个数组，然后是判断这个元素是不是0,如果不是就continue,如果是的话，那么我们使用copy把这个元素之后的切片移动到前面去，然后再把最后一个元素设置成0
     **那么这个做法那里错误了呢？**
     1. 就是有逻辑漏洞！他会中间跳过元素，假设两个连着的0,在遍历第一个0 的时候把第二个0移动到前面了，但是，接着下一个索引的时候是这两个0的下一个元素，相当于把第二个0 没有判断，完美错过了
     2. 其次是时间复杂度太高，假设有n个元素，那么我们不仅for要n词，里面的copy也要n次，所以最后的时间复杂度就是 On2

## 我的代码

（独立完成后再填写或更新）
```go
func moveZeroes(nums []int)  {
    start:=0
    for i,num:=range nums{
        if num!=0 {
            nums[i],nums[start]=nums[start],num
            start++   
        }
    }
}
```

## 参考思路

（独立完成后再整理）
1. 我之前错误的思路是将0移动到数组末尾，但是我们可以换一种思路就是说，让不为0的移动到最前面，在此过程中我们使用**双指针解法**
2. 我们维护一个索引 `i `,代表的是当前遍历的数字，然后再维护一个`start`，代表的是当前的第一个0的位置，也就是可以交换的位置，其实就是两个指针一样
3. 
    循环不变量：在循环过程中，nums 的数据分布始终如下图
    [ 非零元素 | 零元素 |   尚未遍历 ]
                ^           ^
            start0            i
