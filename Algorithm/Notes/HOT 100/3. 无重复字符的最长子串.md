## 我的代码

```go
func lengthOfLongestSubstring(s string) int {
    windows:=[128]bool{}
    left:=0
    ans:=0
    for i,c:=range s{
        for windows[c]{
            windows[s[left]]=false
            left++
        }
        windows[c]=true
        ans=max(ans,i-left+1)
    }
    return ans 
}

```

## 参考思路

（独立完成后再整理）
1. 首次，我们使用数组或者是哈希set用来记录一个字符有没有出现过
2. 其次，我们使用维护一个左窗口left，但是这个题目没有要求窗口的长度，而是计算窗口长度
3. 我们遍历字符串，如果这个字符已经存在，那么我们要一直把左窗口也就是left进行右移，直到这个字符不存在为止，出来循环之后，我们把这个字符标记存在之后，重新计算ans窗口大小
