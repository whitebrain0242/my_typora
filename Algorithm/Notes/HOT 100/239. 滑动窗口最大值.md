```go
func maxSlidingWindow(nums []int, k int) []int {
    ans :=[]int{}
    queue:=[]int{}
    for i,num:=range nums{
        //右边进入
        for len(queue)>0&&num>=nums[queue[len(queue)-1]]{
            queue=queue[:len(queue)-1]
        }
        queue=append(queue,i)

        //左边删除
        left:=i-k+1
        if queue[0]<left{
            queue=queue[1:]
        }

        if left>=0{
            ans=append(ans,nums[queue[0]])
        }

    }
    return ans  
}
```



## 参考思路

（独立完成后再整理）
1. 首先我们维护一个队列，之后开始遍历每一个元素
2. 我们首先要把当前元素加入队列，这个队列就代表有资格成为最大值的候选队列，之后我们把比当前元素更小的元素都提出队列
3. 其次是让最大值出列，我们已经计算当前的做窗口left,如果现在的最大值的索引比left小就代表已经不在窗口中了，我们把他弹出去
4. 最后，如果做窗口合法的话，我们直接把他加入到答案数组中

## 时间复杂度
On,虽然外层是ON,但是内层一个元素一个最多一次入队一次出队，所有元素的内层次数最多是n,所以我们只算外面的

## 空间复杂度
O(min(k,U))，其中 U 是 nums 中的不同元素个数（本题至多为 20001）。双端队列至多有 k 个元素，同时又没有重复元素，所以也至多有 U 个元素，所以空间复杂度为 O(min(k,U))。返回值的空间不计入。
