## 我的易错点

-   首先为什么要使用make,我们直接定义其实也没有什么问题？
     make是用来**预分配容量**的，如果没有make,那么当元素慢慢增加，go运行的时候就会分配更大的桶数组，把旧数据rehash到新桶中，这个过程是grow/rehash 有额外的开销
     我们预分配容量可以减少或者避免扩容：
         减少内存分配次数，减少rehash开销，提升性能
- 最后：为什么是`len(nums)+1`？
         因为计算的是当前元素之前的元素和，所以在数组0的时候，其实是没有一个元素的，和是0,但是我们更要把前缀和为0计数，代表的就是当前元素不需要加任何值本身就符合条件

```go
func subarraySum(nums []int, k int) int {
       cnt:=make(map[int]int,len(nums)+1)
       sum:=0//前缀和！
       ans:=0
       cnt[0]=1
       for _,num :=range nums {
           sum+=num//算出到现在的前缀和
           ans+=cnt[sum-k]
           cnt[sum]++
       }
       return ans 
}
```

（独立完成后再整理）

aaa,其实是这样子、
前缀和：计算的加上当前元素的前面所有元素的和
前缀和数组`cnt`：保存的是所有前缀和出现的次数，这里就直接可以计算（不同个数，不同元素）组成的相同和的组合数量
之后我们怎么计算呢？
我们知道一段连续元素`nums[l-r]`的和就等于`cnt[r+1]-cnt[l]`,我们要求的是`cnt[r+1]-cnt[l]==k`，而`cnt[r+1]=sum`，k已知，我们求`cnt[l]`的数量就是当前前缀和符合条件的个数
