```go
func getIntersectionNode(headA, headB *ListNode) *ListNode {
    p,q:=headA,headB
    for q!=p{
        if p!=nil{
            p=p.Next
        }else {
            p=headB
        }
        if q!=nil{
            q=q.Next
        }else {
            q=headA
        }
    }
    return q
}
```

## 参考思路

（独立完成后再整理）
1. 我们可以知道两个链表都是由各自的不同的部分和相同部分组成，也就是A=a+c,,B=b+c
2. 那么我分别遍历两个链表，然后如果当前走完那么就换到另外一个链表，也就是`p=a+c+b`,`q=b+c+a`，此时他们的长度一定相等，一定会相遇，那么我们也就找到了第一个重合点
3. 我们直接返回
