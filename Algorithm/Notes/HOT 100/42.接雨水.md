```go
func trap(height []int) int {
    ans:=0
    m:=0
    for i,h:=range height{
        if h>height[m]{
            m=i//获得了最大高度的索引
        }
    }
    //然后找左右第二高的
    lh,rh:=0,0
    for _,h:=range height[:m]{
        if h>lh{
            lh=h
            continue
        }
        ans=ans+lh-h       
    }
    for k:=len(height)-1;k>m;k--{
        if height[k]>rh{
            rh=height[k]
            continue
        }
        ans=ans+rh-height[k]
    }
    return ans   
}
```

## 参考思路

（独立完成后再整理）
第一种做法：暴力解法：
1. 首先我们找到在整个数组中最高的那个索引，从而，我们可以把数组分成左右两个部分
2. 假如是左部分，我们从左边向中间进行遍历，维护一个高度最大值left_height，然后遍历得到当前高度h，分两种情况：1. 如果这个h大于left_height的话，那么我们更新left_height，并且跳过这次计数2. 如果没有大于的话，我们直接累加计数，ans+left_height-h
3. 假如是右部分，我们不同的是我们要从最右边也就是数组末尾进行遍历，从右向中间遍历，维护一个right_height，思路一样
4. 怎么理解呢？其实就是我们先在全局找到了一个最大高度，已左边举例，我们维护的leftheight是左边的第二大高度，也就是左边格挡，至于右边格挡全局最大高度已经充当了这个身份，然后我们每一次自己算这个索引也就是这一列能存多少水，也就是leftheight－h的水，之后累加起来就好了
