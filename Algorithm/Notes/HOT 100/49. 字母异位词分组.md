## 我的易错点

-   首先还是哈希表的创建
-  其次是关于转化类型，把Stirng转字节切片，因为GO中的string不可修改，如果要排序的话就必须先转换成[]byte字节数组
- `slices.Sort` 是 Go1.21 + 标准库`slices`包提供的排序函数，按照字母ASCII从小到大排序，之后我们在把排序好的字节数组转换回字符串
- 把这个转换好的字符串作为键，存入哈希表中，把值拼接上去
- `maps.Values(m)`：取出 map 里面**全部的 value**
- `slices.Collect(迭代器)`：把迭代器里所有元素收集，变成`[][]string`二维切片，作为答案返回
    

## 我的代码

（独立完成后再填写或更新）
```go
func groupAnagrams(strs []string) [][]string {
	Map:=map[string][]string {}
	for _,val:=range strs{
		tmp:=[]byte(val)
		slices.Sort(tmp)
		sliced:=string(tmp)
		Map[sliced]=append(Map[sliced],val)
	}
	return slices.Collect(maps.Values(Map))
}
```
