暴力解法：

```go
func findAnagrams(s string, p string) []int {
    //首先我觉得要对p进行排序，然后进行窗口遍历，如果排序之后一样的话那么记录左窗口就是
    tmp:=[]byte(p)
    slices.Sort(tmp)
    n:=len(p)
    left:=0
    w:=[]int{}
    for i:=range s{
        if i-left+1<n{
            continue
        }
        ans:=s[left:i+1]
        b:=[]byte(ans)
        slices.Sort(b)
        if bytes.Equal(tmp,b){
            w=append(w,left)
        }
        left++
    }
    return w
}
```

定长滑动窗口
```go
func findAnagrams(s string, p string) []int {
    cntp:=[26]int{}
    for _,c:=range p{
        cntp[c-'a']++
    }
    cnts:=[26]int{}
    ans:=[]int{}
    for right,c:=range s{
        cnts[c-'a']++
        left:=right-len(p)+1
        if left<0{
            continue
        }
        if cnts==cntp{
            ans=append(ans,left)
        }
        cnts[s[left]-'a']--
    }
    return ans 
}
```

1. 其实思路没有差多少，只是说我是直接排序字符串比较字符串
2. 但是定长滑动窗口是保存在map哈希表中，比较的时候我们直接比较map就可以
3. 对于每一个出现的字符我们直接在map中进行累加就ok
