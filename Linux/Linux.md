#### ls（list）

**ls 就是：看文件夹里有啥**

在 Linux 里，输入 `ls` 回车，它就会**列出当前文件夹里的文件和目录**。

```c
ls [选项] [文件/目录路径]
```

**常用参数**

直接用 ls-只显示**名字**，不显示别的，简单列表。

| 选项           | 功能                                             | 示例              |
| -------------- | ------------------------------------------------ | ----------------- |
| `-l`           | 长格式（权限、链接数、所有者、大小、时间、名称） | `ls -l`           |
| `-a`           | 显示所有文件（含 `.` 开头的隐藏文件）            | `ls -a`           |
| `-h`           | 配合 `-l`，以**人类可读单位**显示大小（K/M/G）   | `ls -lh`          |
| `-t`           | 按**修改时间**排序（最新在前）                   | `ls -lt`          |
| `-r`           | 反向排序（与 `-t`/`-S` 配合）                    | `ls -ltr`         |
| `-S`           | 按**文件大小**排序（最大在前）                   | `ls -lS`          |
| `-R`           | 递归列出所有子目录内容                           | `ls -R`           |
| `-d`           | 仅显示目录本身，不展开内容                       | `ls -d /etc`      |
| `-F`           | 给文件加类型标识（`/`目录、`*`可执行、`@`链接）  | `ls -F`           |
| `--color=auto` | 颜色区分文件类型（目录蓝、可执行绿等）           | `ls --color=auto` |

**组合参数**

```c
ls -lh
l：显示详细信息
h：大小变成 KB/MB，看得懂
     
ls -alh
a：显示隐藏文件
l：详细
h：大小好看
     
     ls -lt
l：详细
t：按修改时间排序
     
     ls -ltr
l：详细
t：按时间
r：反过来排
     
     ls -lS
l：详细
S：按大小从大到小
```

想看详情 → `-l`

想看大小 → `-h`

想看隐藏 → `-a`

想按时间 → `-t`

想反过来 → `-r`

想按大小 → `-S`

#### mkdir

全称 **make directory**，作用是**创建新文件夹（目录）**

1. **递归创建多层文件夹（核心参数 -p）**

如果想创建**嵌套文件夹**（比如 `project/src/utils`），直接写会报错，必须加 `-p` 参数：

```
mkdir -p 多层目录路径
```

示例：一次性创建 project → src → utils 三层文件夹

```
mkdir -p project/src/utils
```

✅ 作用：即使父目录不存在，也会自动创建，不会报错。

2. **创建带权限的文件夹（Linux/macOS）**

用 `-m` 参数指定文件夹权限（适合服务器 / 开发场景）：

```
mkdir -m 755 文件夹名
```

示例：创建权限为 755 的 `data` 文件夹

```
mkdir -m 755 data
```

#### `rm`

（remove）删除文件 / 目录，**删除后默认不进回收站、难以恢复**，使用需格外谨慎。

| 选项              | 作用       | 说明                                   |
| ----------------- | ---------- | -------------------------------------- |
| `-f`              | 强制删除   | 不提示、忽略不存在文件，覆盖只读权限   |
| `-i`              | 交互确认   | 每删一个都提示 `y/n`，防误删           |
| `-r`/`-R`         | 递归删除   | 必须加才能删**非空目录**               |
| `-v`              | 显示详情   | 打印每个被删文件 / 目录路径            |
| `-I`              | 精简交互   | 删≥3 个文件或递归时才提示一次          |
| `--preserve-root` | 保护根目录 | 默认开启，禁止 `rm -rf /` 删系统根目录 |

#### find

**全盘 / 指定目录找任意文件 / 目录**（万能查找）

在**指定目录下递归查找文件 / 目录**，支持按**名字、大小、类型、时间、权限**搜索。

```c
# 1. 按文件名查找（当前目录找所有 .log 文件）
find  -name "*.log"

# 2. 根目录全盘找 nginx.conf
find / -name "nginx.conf"

# 3. 忽略大小写查找
find / -iname "readme.txt"

# 4. 只找目录（不找文件）
find /home -type d -name "project"

# 5. 只找普通文件
find . -type f -name "*.txt"

# 6. 找大于 100MB 的文件
find / -size +100M

# 7. 找 7天内修改过的文件
find . -mtime -7
```

#### chmod

change mode修改（文件 / 目录的访问）模式 / 权限

语法核心：`chmod [权限参数] [文件名/目录名]`

1. 权限的数字对应规则

Linux 用**二进制转十进制**给权限赋值，3 种基础权限的固定数值：

| 权限 | 字母 | 二进制 | 十进制值 |
| :--- | :--- | :----- | :------- |
| 读   | r    | 100    | 4        |
| 写   | w    | 010    | 2        |
| 执行 | x    | 011    | 1        |

`chmod` 的 3 位数字，分别对应 ** 所有者 (u)、所属组 (g)、其他用户 (o)** 的权限总和：

-  第 1 位（所有者）：`r+w+x = 4+2+1 = 7` → 自己可读可写可执行

-  第 2 位（所属组）：`无权限 = 0` → 组内用户无任何权限

-  第 3 位（其他用户）：`无权限 = 0` → 其他用户无任何权限

   ```c
   chmod 755 /tmp/test.sh
        
   ```

   

#### ps

Process Status 查看进程状态

```c

```

`a`：显示所有用户的进程

#### netstat

```c
# 查看8080端口占用
netstat -tulnp | grep 8080
```

参数说明：

-  `-t`：显示 TCP 端口
-  `-u`：显示 UDP 端口
-  `-l`：仅显示监听状态的端口
-  `-n`：以数字形式显示 IP / 端口，不解析域名
-  `-p`：显示占用端口的进程 PID / 名称

### 文件系统结构

**什么是路径？**

路径 = 文件 / 目录在系统里的**地址**

Linux 一切皆文件，所有东西都靠路径找。

#### 绝对路径、相对路径

**绝对路径**（Absolute Path）：从根目录 `/` 开始写的完整路径

特点

-  以 `/` 开头
-  唯一、准确
-  不受当前位置影响

**相对路径**（Relative Path）：相对于你当前所在目录的路径

特点

-  不以 `/` 开头
-  依赖当前位置（pwd 看到的位置）
-  写起来短

#### 特殊路径符

1. `.`  当前目录

```
./file.txt
```

就是当前目录下的 file.txt

2. `..` 上一级目录

```
cd ..或者cd../..回退两级
```

回到上一层

3. `~` 当前用户的家目录

-  root → `/root`
-  普通用户 → `/home/用户名`

```
cd ~
cd ~/test
```

4.  `-` 回到上一次所在的目录

```
cd -
```
